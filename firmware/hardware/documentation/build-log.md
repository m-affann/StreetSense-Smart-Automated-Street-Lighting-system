# StreetSense Build Log

## Project Overview
This document records the development, hardware assembly, firmware development, and progress of StreetSense: Smart Automated Street Lighting System.

## Development Progress

### Initial Development
- Planned the automated street lighting concept.
- Identified the required electronic components.
- Prepared the hardware development setup.

### Hardware Assembly
- Connected the Arduino Uno R3 compatible board.
- Integrated the ultrasonic distance sensor.
- Installed six white LEDs and their current-limiting resistors.
- Connected the electronic components using a solderless breadboard and jumper wires.
- Worked on assembling the physical streetlight prototype.

### Firmware Development
- Developed Arduino firmware for ultrasonic distance measurement.
- Implemented LED control logic.
- Worked on coordinating the LED lighting zones according to distance readings.
