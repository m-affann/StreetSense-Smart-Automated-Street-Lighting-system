
# StreetSense Project Media

## Overview
This directory contains photographs and videos documenting the development of StreetSense: Smart Automated Street Lighting System.

The media provides visual evidence of the hardware assembly, electronic connections, testing process, and working prototype.

## Project Documentation

### Hardware Assembly
Photographs showing the Arduino board, ultrasonic sensor, LEDs, breadboard, and wiring connections.

### Prototype Development
Images documenting the physical construction and development of the StreetSense prototype.

### Testing and Demonstration
Videos and photographs demonstrating the three distance-based lighting zones:

- Zone 1: LEDs 1 and 2 activate when an object is close.
- Zone 2: LEDs 3 and 4 activate when an object moves farther away.
- Zone 3: LEDs 5 and 6 activate when an object moves farther away again.

## Media Files
Project photographs and demonstration videos will be organized in this directory.

## Development Evidence
The photographs and videos document the actual development and testing process of StreetSense.
