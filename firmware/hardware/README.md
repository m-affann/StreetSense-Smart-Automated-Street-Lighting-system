# StreetSense Hardware Documentation

## Overview
This directory contains the hardware documentation for StreetSense, a smart automated street lighting system.

The system uses an ultrasonic distance sensor connected to an Arduino to detect nearby objects and control six LED streetlights.

## Main Hardware Components
- Arduino Uno R3 compatible board (ATmega328P)
- Ultrasonic distance sensor
- Six white 5mm LEDs
- 220-ohm resistors
- 400-point solderless breadboard
- Male-to-male Dupont jumper wires
- Male-to-female Dupont jumper wires

## Circuit Design
The Arduino acts as the main controller of the system.

The ultrasonic sensor measures the distance of nearby objects. Based on the measured distance, the Arduino controls the LED streetlights.
